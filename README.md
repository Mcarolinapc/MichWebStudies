# MichWebStudies - Digital Garden & Tech Documentation 

**MichWebStudies** es mi espacio personal de documentación técnica y apuntes de ingeniería de software. Construido como un sitio web estático, este proyecto centraliza mi aprendizaje, diagramas y referencias sobre arquitecturas, lenguajes de programación y herramientas de despliegue.

---

##  Propósito del Proyecto

El objetivo de este repositorio es aplicar la filosofía del **"Aprender en Público"** (Learning in Public) y mantener un *Digital Garden* vivo. Me permite estructurar mi conocimiento de forma modular y tener una referencia rápida (y accesible desde cualquier lugar) de las tecnologías con las que trabajo en mi día a día.

---

##  Ecosistema de Contenidos

El sitio web está estructurado en diferentes dominios tecnológicos reflejados en sus respectivos archivos `.qmd`:

* ** Mobile Development**: Android Studio, Kotlin, Jetpack Compose.
* ** Backend & APIs**: Java, Spring Boot, Node.js.
* ** Bases de Datos**: SQL (PostgreSQL, MySQL), Neo4j (Grafos).
* ** DevOps & Tools**: Git, GitHub Actions, despliegues y metodologías.
